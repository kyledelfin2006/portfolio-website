I value simple systems that are easy to understand and maintain. I apply YAGNI: build what the problem needs today, and introduce complexity only when there is a concrete reason for it.

For backend services, that means modular Spring Boot REST APIs, clear layers, decoupled components, and explicit PostgreSQL schemas with Flyway migrations. Docker helps keep development and deployment environments reproducible. For a local desktop tool, a small Python modular monolith can be the right fit.

My AI engineering focus is autonomous agents and prompt fine-tuning for reliable outputs. I’m continuing to learn how to integrate AI responsibly into production systems.
